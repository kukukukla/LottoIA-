3. ALGORITMOS IMPLEMENTADOS
═══════════════════════════════════════════════════════════════════════════════

  ┌── ANÁLISE ESTATÍSTICA ─────────────────────────────────────────────────┐
  │ • Frequência absoluta/relativa/por janela (O(n))                       │
  │ • Atraso atual/médio/máximo (O(n))                                     │

5. MÉTODOS DE GERAÇÃO DE JOGOS
═══════════════════════════════════════════════════════════════════════════════

  7. ESTRATÉGIA         → Usa filtros configuráveis da estratégia salva
  8. DESDOBRAMENTO      → Combinações de dezenas base
  9. GENÉTICO           → Algoritmo evolutivo com fitness configurável
  10. ML                → Baseado em predições de modelos de ML

6. COMO O SISTEMA FUNCIONA
═══════════════════════════════════════════════════════════════════════════════

  FLUXO DE DADOS:
  ─────────────────

  1. INGESTÃO
     → Concursos históricos são carregados no banco PostgreSQL
     → Cada concurso armazena: número, data, dezenas, estatísticas derivadas

  2. PROCESSAMENTO ESTATÍSTICO
     → MotorEstatistico calcula métricas em tempo de execução
     → Cache no Redis para consultas frequentes
     → Atualização automática quando novos concursos são adicionados

  3. ANÁLISE MULTIDIMENSIONAL
     → Múltiplos motores analisam os dados simultaneamente
     → Cada motor fornece uma "visão" diferente dos dados
     → Resultados são combinados no MotorPrincipal

  4. GERAÇÃO DE JOGOS
     → Usuário seleciona método (aleatório, score, estratégia, etc.)
     → Sistema aplica filtros e validações
     → Cada jogo recebe metadados explicando sua composição

  5. SIMULAÇÃO E VALIDAÇÃO
     → Estratégias são testadas em backtests históricos
     → Monte Carlo compara com distribuição aleatória
     → Testes estatísticos verificam aleatoriedade dos dados

  6. EXPORTAÇÃO
     → Relatórios em JSON, CSV ou formato executivo
     → Jogos exportáveis para conferência

  IMPORTANTE:
  ────────────
  • O sistema NÃO prevê resultados futuros
  • Toda análise é descritiva, baseada em dados históricos
  • Probabilidades reais de acerto seguem a matemática combinatória
  • O objetivo é estudo quantitativo e experimentação de estratégias

  $ cd /mnt/agents/output
  $ python demo.py

  OPÇÃO 2: USO PROGRAMÁTICO VIA ORQUESTRADOR
  ───────────────────────────────────────────
  from main_engine import MotorPrincipal
  from models import Concurso, LoteriaTipo

  # Carregar concursos do banco de dados
  concursos = [...]  # lista de objetos Concurso

  # Inicializar sistema
  motor = MotorPrincipal(concursos)

  # Análise completa
  analise = motor.analise_completa()

  # Gerar jogos por score
  jogos = motor.gerar_jogos("score", n_dezenas=15, n_jogos=5)

  # Criar estratégia personalizada
  from models import EstrategiaConfig
  config = EstrategiaConfig(
      nome="Minha Estratégia",
      loteria=LoteriaTipo.LOTOFACIL,
      quantidade_dezenas=15,
      filtros={
          "frequencia_historica": {"max_rank": 15},
          "dezenas_atrasadas": {"min_atraso": 2, "max_atraso": 10},
          "equilibrio_par_impar": {"pares": 7, "impares": 8}
      }
  )
  id_estr = motor.criar_estrategia(config)
  jogos_estr = motor.gerar_por_estrategia(id_estr, n_jogos=3)

  # Simulação Monte Carlo
  relatorio = motor.simular_monte_carlo(n_simulacoes=1000)

  # Testar aleatoriedade
  testes = motor.testar_aleatoriedade()

  # Relatório executivo
  rel_exec = motor.relatorio_executivo()

10. CONSIDERAÇÕES FINAIS E AVISOS
═══════════════════════════════════════════════════════════════════════════════

  ⚠️  AVISO IMPORTANTE:
  ─────────────────────
  Este sistema é uma FERRAMENTA DE ANÁLISE ESTATÍSTICA e NÃO um sistema
  de previsão de resultados de loteria. Sorteios são eventos aleatórios
  independentes e a probabilidade real de acerto é determinada pela
  matemática combinatória (C(n,k)), não por análise histórica.

  O QUE O SISTEMA FAZ:
  ✓ Analisa padrões históricos de forma quantitativa
  ✓ Permite experimentar estratégias de composição de jogos
  ✓ Gera combinações segundo critérios matemáticos configuráveis
  ✓ Simula estratégias em dados históricos para avaliação
  ✓ Exporta relatórios e estatísticas para estudo

  O QUE O SISTEMA NÃO FAZ:
  ✗ Prever resultados futuros de sorteios
  ✗ Aumentar as probabilidades reais de acerto
  ✗ Garantir retorno financeiro
  ✗ Substituir o julgamento do usuário

  RECOMENDAÇÕES:
  ───────────────
  • Use o sistema como apoio ao estudo, não como única base de decisão
  • Lembre-se que cada sorteio é um evento independente
  • Jogue com responsabilidade e dentro de sua capacidade financeira
  • Considere os jogos como entretenimento, não investimento
